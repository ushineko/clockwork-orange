### Summary

Adds `internal/gui` and wires `cmd/clockwork-orange-gui` (stdlib flags
`--section --scheme --config --version`). The design system is copied from
nmsbonker: `theme.go`, `fonts.go`, `cursor_*.go` byte-identical modulo the
module path; `views_table.go` gains an optional 64 px thumbnail column;
`views_appearance.go` and `dialogs.go` adapted as the spec lists. The shell
(nav list, header, status bar, busy popup, flash banners) is nmsbonker's.
Sections per R7.3: Service (Linux) or Activity, Local / Wallhaven /
Duckduckgo Images (form generated from the plugin schema, Download Now,
Reset & Run, image review with keyboard marking and Apply Blacklist),
History, Blacklist (filter, thumbnails, click-to-select, Remove Selected),
Settings (Basic, Advanced, read-only Raw YAML, 1 s coalesced auto-save),
Appearance, About (embedded README). Tray with Show / About / Quit, close
intercept hides to the tray and notifies, second instance exits silently.
The wallpaper timer runs `core.Cycle` on `default_wait`, first fire at 2 s,
and idles while the daemon holds the cycling lock (DV10). The parity guard
now compares CLI leaves with `gui.Actions()` both ways.

Core additions: `AvailablePlugins()` (registry with schemas, no stores),
`TryGUILock()`, `PluginResultPath`. `go mod tidy` pulled Fyne's transitive
dependencies into go.sum; `golang.org/x/net` bumped v0.35.0 → v0.56.0.
