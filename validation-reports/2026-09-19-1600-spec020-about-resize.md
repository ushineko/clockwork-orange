## Validation Report: Spec 020 — The About section resizes smoothly

**Date**: 2026-09-19 16:00
**Spec**: specs/020-about-resize.md
**Issue**: #26
**Status**: PASSED

### Summary

Dragging the window with About showing was jerky. A 20-second CPU profile,
taken through spec 017's endpoint on v4.3.0 during a real drag:

                                cum     cum%
    markdown.(*Pane).Resize    3.18s   41.90%
    markdown.(*Pane).measure   2.40s   31.62%
    glfw.MakeContextCurrent    1.62s   28.32%

A third of all CPU is the markdown pane re-measuring — it renders every block
to ask its height, on every width change, and a drag is hundreds of them. The
call arrives through `glfwPollEvents → processResized`, which is Fyne relaying
out synchronously inside the event poll, so the queue cannot drain while it
runs.

fynedesygn 0.1.29 (its spec 015) adds `markdown.Options.SettleResize`; this
bumps the library from v0.1.25 and sets 120ms on the README pane.

**A note on the report.** The reporting machine was on **v4.2.0**, five
releases behind. Updating to v4.3.0 turned the hang into jerkiness before any
of this landed. Checking the running build is the cheapest first step in a
report like this, and it was not the first thing checked.
